Quick start

Common actions at a glance. Everything works with mouse, touch, or keyboard — no configuration needed beyond adding your cameras.

Viewing

First launch

After installing PTZLite, it appears in your Start Menu. When launched it starts a local web server on port 8765 and opens your browser automatically at http://localhost:8765.

On first launch you will see an empty grid — no cameras are configured yet. Click the Settings (gear ⚙) icon in the top-right of the header to add your first camera.

System tray

PTZLite runs as a background service in the Windows system tray (bottom-right of your taskbar). Right-click the tray icon to access:

  • Open Viewer — opens the viewer in your browser (same as double-clicking the icon).
  • Settings — opens the camera settings page directly.
  • Exit — shuts down PTZLite completely.

You can also press Ctrl+Alt+Z at any time — even when the browser is closed — to open the viewer instantly. See System tray & hotkey for details.

Tip: PTZLite runs entirely on your local network. No data is sent to the internet and no account is required.

Adding a camera

  1. Click the Settings icon (⚙) in the header.
  2. Click Add camera (the dashed card at the end of the list).
  3. Fill in the camera details — see Camera fields explained below.
  4. Click Test connection to verify the RTSP stream is reachable before saving.
  5. Click Save. The camera appears in the viewer immediately.
Tip: Make sure your camera is on the same local network as your PC and that RTSP streaming is enabled in the camera's own settings.

Camera fields explained

Camera IDA unique internal identifier using letters, numbers and underscores. Auto-filled from the name. Used in URLs — keep it short and simple.

PTZ-specific fields

FieldDescription
Horizontal FoV (°)Camera's horizontal field of view in degrees. Used to calculate pan distance for click-to-centre. Check your camera's datasheet — typical values range from 60° to 100°.
Vertical FoV (°)Camera's vertical field of view in degrees. Used to calculate tilt distance. Typical values: 40–70°.
PTZ speed (1–63)Motor speed for pan and tilt commands. Higher values move faster. For ONVIF cameras this is normalised to a 0–1 velocity internally.
Zoom speed (1–63)Optical zoom motor speed. Applies to both scroll-wheel zoom and right-button+scroll zoom.
Zoom step duration (s)How long each zoom action runs the motor. Increase if the zoom moves too little per scroll tick.
Camera rotation speed (°/s)Approximate pan/tilt degrees per second at the configured PTZ speed. Used to calculate timed move duration for click-to-centre. Tune this if the camera consistently under- or over-shoots.
Monitor preset IDA preset the camera returns to after PTZ inactivity. The preset must already be defined on the camera. Leave blank to disable.
Invert pan / Invert tiltReverses the pan or tilt direction. Use if the camera moves in the wrong direction when you click or drag.

Pages & groups

The Page / Group field assigns a camera to a named group. All cameras in the same group are shown together when you navigate to that group in the viewer.

In the camera add/edit form, the Page field is a dropdown showing all existing page names. Select an existing page to add the camera to it, or choose + New page… and type a new name.

When at least one camera has a page assigned, the viewer header shows a dropdown selector listing all group names — click it to jump directly to any group. Within a group, if there are more cameras than the current layout can show, ‹ › pagination arrows appear alongside the dropdown.

Cameras with no page assigned are shown together on the default (unnamed) group.

Example: Create groups named "Indoor", "Outdoor", and "Garden" to organise 12 cameras across three views, each showing a 2×2 grid.

Fill frame (crop mode)

By default, camera feeds are letterboxed — the full video is visible with bars on the sides or top if the aspect ratio does not match the tile.

Enabling Fill frame for a camera forces the video to expand and fill the entire tile, cropping the edges instead of letterboxing. This is most useful for:

  • Doorbell cameras that output a portrait or 4:3 image.
  • Any camera where black bars look unsightly in the grid.

Enable it via Settings → edit the camera → Fill frame (crop to fit) checkbox. Cameras with crop mode active show a purple Crop badge in the camera list.

Reolink cameras

Reolink cameras use the native Reolink HTTP API for PTZ commands and token-based authentication. Set Brand to Reolink.

RTSP URL format

rtsp://username:password@ip:554/h264Preview_01_main

The channel number is embedded in the stream name: channel 0 = _01_, channel 1 = _02_, and so on.

Requirements

  • RTSP must be enabled in the camera's Network settings.
  • The camera must be on the same subnet as your PC.
  • RTSP port is 554. Management port for PTZ defaults to 443.

Reolink Home Hub Pro

The Hub Pro is a wireless NVR. Each physical camera is a separate channel — add one PTZLite entry per camera channel.

Setup

  • Set IP to the Hub Pro's IP address (individual cameras are wireless and have no direct IP).
  • Set Channel to the camera index shown in the Reolink app (0-based: first camera = 0).
  • Use the Hub Pro's admin username and password.

Recommended stream setting

Use Sub stream for Hub Pro cameras. The main stream is H.265 which some browsers cannot decode natively. The sub stream uses H.264 and plays reliably in all browsers.

Tip: If you see a black screen or buffering on a Hub Pro camera, switch to Sub stream using the Main/Sub buttons in the header.

Dahua cameras

Dahua cameras use a different RTSP URL format and the CGI API for PTZ. Set Brand to Dahua.

PTZLite uses absolute position PTZ for Dahua — the same approach as SmartPSS Lite. Click-to-centre reads the camera's current pan/tilt angle, calculates the exact target, and moves there in a single command. No timed movement estimation is needed.

RTSP URL format

rtsp://username:password@ip:554/cam/realmonitor?channel=1&subtype=0

subtype=0 = main stream, subtype=1 = sub stream. Channel is 1-based for Dahua.

Notes

  • Set Channel to 1 for the first camera (Dahua is 1-based, unlike Reolink).
  • Management port is typically 80 for older devices and 443 for newer ones.

Other ONVIF cameras

Any ONVIF-compatible camera can be added for live streaming alongside Reolink and Dahua cameras. Set Brand to ONVIF.

PTZ support uses the ONVIF ContinuousMove command for joystick control and timed movement for click-to-centre. Results vary by camera — not all cameras implement the full ONVIF PTZ profile.

Note: Click-to-centre accuracy for ONVIF cameras depends on the Camera rotation speed (°/s) setting being correctly tuned. Cameras that do not report their position via ONVIF use timed movement estimates which may under- or over-shoot until the speed value is calibrated.

Managing cameras

Reordering

Drag camera cards in the Settings list to reorder them. The order here determines the order cameras appear in the viewer grid. Changes take effect immediately.

Enabling and disabling

Each camera card has a toggle switch. Disabling a camera hides it from the viewer and stops its RTSP stream — useful for cameras that are temporarily offline. All settings are preserved.

Export and import

Use the Export JSON button to download all camera configurations as a JSON file. Use Import JSON to restore from a backup or migrate to another PC. Importing replaces your entire current camera list.

Network scan

Click Scan network to discover ONVIF-compatible devices on your local network using WS-Discovery. Discovered devices appear below the camera list — click one to pre-fill the add-camera form with its IP address and model name.

Fullscreen grid

Click the ⛶ fullscreen icon in the header to expand the entire camera grid to fill the browser window, hiding the header bar. This is useful for wall-mounted monitoring displays. Press Esc or click the icon again to exit.

Main vs Sub stream

The Main and Sub buttons in the header switch all cameras simultaneously between their full and reduced resolution streams.

  • Main stream — full resolution (e.g. 4K or 5MP). Higher bandwidth and CPU.
  • Sub stream — reduced resolution (typically 720p). Lower bandwidth, smoother with many cameras simultaneously.

Switching streams briefly reconnects all video feeds. The per-camera stream quality set in Settings is the startup default; the Main/Sub buttons override it globally for the current session.

Tip: With 9 or 16 cameras, Sub stream gives significantly smoother playback and lower CPU usage.

Fullscreen (single camera)

There are three ways to go fullscreen on a single camera:

  • Double left-click anywhere on a camera tile — the camera fills the entire screen instantly.
  • Hover over the tile and click the ⛶ button that appears in the top-right corner.

To exit fullscreen:

  • Double right-click anywhere on the camera tile.
  • Press Esc.
  • Click the fullscreen button again (visible while in fullscreen mode).

When entering fullscreen, PTZLite automatically switches that camera to the Main stream (full resolution) regardless of the current global stream setting. When you exit fullscreen, the camera reverts to whichever stream was active before — Sub, Main, or any other setting.

Note: For PTZ cameras, the double-click is intercepted so the single-click PTZ action is slightly deferred (about 280 ms). A very fast double-click goes fullscreen without triggering PTZ movement.

Camera labels

Camera name labels are displayed on each tile by default. Click the label toggle button (eye icon) in the header to hide or show all labels. Your preference is saved across sessions.

Audio control

Each camera tile has an individual mute/unmute button in the bottom-right area of the tile (second from the right), visible when you hover over the tile. All cameras start muted by default — browsers block autoplay with sound.

Click the speaker icon to unmute a camera's audio stream. The mute state for each camera is remembered across layout changes and page navigation.

Tip: Unmute only one camera at a time to avoid overlapping audio from multiple feeds.

Snapshot

The snapshot button (camera icon) sits at the far bottom-right of each camera tile, visible on hover. Click it to save a still image from the current video frame as a PNG file, automatically named after the camera with a timestamp.

The file is downloaded to your browser's default downloads folder.

Digital zoom

Scroll the mouse wheel over any camera tile to zoom into the video feed. This is a client-side crop — it magnifies the existing video without controlling the camera's optical zoom.

  • Scroll up — zoom in.
  • Scroll down — zoom out back toward 1:1.
  • Click and drag while zoomed in — pan the zoomed view.

Digital zoom is independent of optical PTZ zoom and can be used together with it. At very high magnification individual pixels become visible.

Optical zoom via scroll: On PTZ cameras, holding the right mouse button while scrolling drives the camera's physical zoom motor instead of applying digital zoom. See Optical zoom.

Pages & pagination

When you have more cameras than the current layout can show at once, navigation controls appear in the header:

  • If cameras are assigned to named groups — a dropdown selector lists all group names. Select a group to jump to it. If a group has more cameras than the layout shows, ‹ › arrows appear alongside the dropdown to page through them.
  • If no groups are defined — ‹ › arrows and a page counter (e.g. 2 / 3) appear to page through all cameras.

On mobile, large ‹ › buttons appear in the bottom navigation bar for the same purpose.

Keep streams live

By default, PTZLite automatically pauses all video streams when you switch to another browser tab or minimise the window — saving bandwidth and CPU while you are away. Streams resume the moment you return to the tab.

Click the Keep Live button (Wi-Fi icon) in the header to disable this behaviour. When active (button turns blue), all streams continue playing even when the tab is in the background. This is useful if you want PTZLite to keep recording or monitoring while you work in other windows.

Your Keep Live preference is saved across sessions.

Click to centre

For PTZ-enabled cameras, a single click anywhere on the video pans and tilts the camera so that the clicked point becomes the new centre of the frame.

A white ripple animation confirms the target location. The camera begins moving within a fraction of a second. The technique used depends on the camera brand:

  • Reolink: Timed open-loop movement. The click position is converted to a pan/tilt angle using the configured FoV. The camera is driven for a calculated duration based on the rotation speed setting, then stopped.
  • Dahua: CGI absolute positioning — the same method used by SmartPSS Lite. The current pan/tilt angle is read from the camera, the target angle is calculated, and a single absolute move command is sent. This is genuinely precise in one step.
  • ONVIF: Timed ContinuousMove. Similar to Reolink — accuracy depends on the rotation speed setting being correctly calibrated.
Tuning timed moves: If the camera consistently stops short of the target, increase Camera rotation speed (°/s). If it over-travels, decrease it. For Dahua cameras the move is exact — if it misses, check that the camera's getStatus CGI is responding correctly.

Joystick drag

Click and hold on a PTZ camera tile, then drag in any direction to move the camera continuously. Release the mouse button (or lift your finger on touch) to stop.

  • A circular ring and knob indicator appears at the point where you pressed, showing joystick displacement.
  • Distance from the origin controls speed — drag further from the centre point for faster movement.
  • The camera keeps moving as long as you hold and drag. Commands are sent every 80 ms while the joystick is active.
  • If you press and release without dragging more than a few pixels it is treated as a click-to-centre command rather than a joystick move.

After a joystick move, Dahua cameras invalidate their tracked position so the next click-to-centre will re-query the camera's current angle rather than using stale data.

Touch / mobile PTZ

All PTZ controls work on touch screens with the same gestures as mouse:

  • Tap quickly on a PTZ camera — click-to-centre.
  • Press and drag — joystick control; lift finger to stop.
  • Scroll / pinch — digital zoom in/out.
  • Drag while zoomed in — pan the digital zoom view.

On mobile, the layout is automatically switched to 1×1 (one camera at a time) and a bottom navigation bar replaces the header pagination controls. Use the bottom ‹ › buttons to move between cameras or groups.

Optical zoom

For PTZ cameras with a motorised zoom lens, PTZLite provides two ways to control optical zoom:

Right mouse button + scroll wheel

Hold down the right mouse button while scrolling the wheel over a PTZ camera tile:

  • Scroll up — zoom in (telephoto).
  • Scroll down — zoom out (wide angle).

Multiple scroll ticks are batched over 120 ms and sent as a single command with a step count, preventing a flood of individual API requests.

Zoom speed and step duration

Two settings in the camera configuration control zoom behaviour:

  • Zoom speed (1–63) — how fast the zoom motor runs. Higher = faster.
  • Zoom step duration (s) — how long the motor runs per zoom action. Increase this if each tick zooms too little.
Tip: Optical zoom is separate from digital zoom. You can combine both — digitally zoom in on a digitally zoomed view, then use optical zoom to bring in the real image.

Presets

Camera presets are saved PTZ positions defined on the camera. If your camera has presets configured, up to four are shown as buttons along the bottom of the camera tile.

Click a preset button to move the camera to that saved position immediately.

Presets are defined on the camera itself (via the Reolink app, SmartPSS, or the camera's web interface) — you cannot create or rename presets from within PTZLite. PTZLite reads them automatically when the camera tile loads.

Monitor preset

The optional Monitor preset ID field in Settings adds a permanent Monitor button to the camera tile (styled differently from regular presets). Click it to return the camera to its defined monitoring position at any time.

After a joystick move or preset jump, Dahua cameras clear their tracked position cache so the next click-to-centre re-reads the actual camera position rather than using potentially stale data.

Light / Dark mode

Click the sun/moon icon (☀) in the header to switch between dark and light mode. Your preference is saved and applied instantly across all PTZLite pages — viewer, settings, help, and login.

Security & password

PTZLite can be protected with a password so that only authorised users on your network can access the viewer and settings.

Setting a password

  1. Open Settings and scroll to the Security section.
  2. Enter a new password in both fields and click Save password.
  3. From this point on, anyone accessing PTZLite (on any device on your network) will be shown a login page first.

Removing the password

Leave both password fields blank and click Save password to remove password protection entirely.

Sessions

After a successful login, a session cookie is stored in the browser. Sessions are invalidated if PTZLite is restarted — you will be prompted to log in again after a restart.

Tip: PTZLite only listens on localhost by default. If you want to access it from other devices on your network, ensure your firewall allows connections to port 8765.

System tray & hotkey

System tray icon

PTZLite runs as a background Windows application with no visible command window. Its icon appears in the system tray (bottom-right corner of your taskbar). Right-click the icon for these options:

  • Open Viewer — opens http://localhost:8765 in your default browser.
  • Settings — opens the Settings page directly.
  • Exit — shuts down PTZLite and go2rtc completely.

Ctrl+Alt+Z global hotkey

Pressing Ctrl+Alt+Z opens the PTZLite viewer in your browser from anywhere in Windows — even when the browser is closed or minimised. The hotkey is registered globally so it works regardless of which application has focus.

If registration fails (shown in the application log), another application on your system has already claimed that key combination.

Tip: If the browser window is already open on the PTZLite tab, the hotkey simply opens a new tab rather than focusing the existing one — this is a browser behaviour limitation.

Stream health & reconnect

The small dot in the viewer header shows the status of the go2rtc stream engine that handles RTSP-to-WebRTC conversion:

  • ● Green — stream engine running normally.
  • ● Red — stream engine offline or not responding to API calls.
  • ● Grey — status not yet confirmed / checking.

PTZLite checks health every 15 seconds. If go2rtc goes offline it is restarted automatically — once per 60 seconds across all open browser tabs to prevent multiple tabs triggering simultaneous restarts.

Click the dot at any time to force an immediate engine restart and reconnect all streams.

Per-camera reconnect

Individual cameras show a ⚠ Stream offline overlay if their specific stream drops. The Reconnect button performs a smart recovery:

  • If go2rtc is still healthy, only that camera's WebRTC connection is bounced — other cameras are unaffected.
  • If go2rtc itself is down, a full engine restart is performed instead.

View log

PTZLite writes a detailed application log covering startup, camera connections, PTZ commands, stream health events, and errors. To view it:

  1. Open Settings.
  2. Click View Log in the Settings header bar.

The log viewer opens as an overlay panel. Features:

  • Colour coding — errors in red, warnings in amber, info lines in grey, debug lines in the default colour.
  • Most recent first — newest log lines appear at the top.
  • Line count selector — choose 200, 500, 1000, or 2000 lines to display.
  • Refresh — reloads the log from disk.
  • Save — downloads the current log view as a .log file with a timestamp in the filename.

The log file is written to ptzlite.log in the PTZLite install directory (%LOCALAPPDATA%\Programs\PTZLite\). This file is always available even if the log viewer cannot be reached.

Troubleshooting

Black screen / buffering on camera

  • Switch to Sub stream — main stream may be H.265 which some browsers cannot decode (particularly Reolink Hub Pro cameras).
  • Check the camera is online and reachable by pinging its IP from your PC.
  • Confirm RTSP streaming is enabled in the camera's own settings.
  • Click the stream health dot in the header to restart the stream engine.
  • Use the per-camera Reconnect button on the offline overlay to restart just that stream.

PTZ click does nothing or moves the wrong way

  • Confirm PTZ enabled is checked for that camera in Settings.
  • Verify the camera IP, management port, username, and password are correct.
  • If the camera moves in the wrong direction, enable Invert pan or Invert tilt in Settings.
  • If click-to-centre consistently over- or under-shoots, adjust Camera rotation speed (°/s) in Settings.

Camera added but not showing in viewer

  • Check the camera is Enabled in Settings (the toggle on the camera card).
  • If the camera is on a named page, select that page from the group dropdown in the viewer header.
  • Try a browser refresh (F5) after adding or modifying a camera.

Optical zoom much slower than the camera's native app

  • Increase Zoom speed in Settings (up to 63).
  • Increase Zoom step duration so each scroll tick drives the motor for longer.
  • Speed 63 maps to the camera's maximum zoom velocity — if the native app appears faster it may be using a different internal protocol or UI scaling.

App doesn't open on launch

  • Check the system tray — PTZLite may be running but the browser didn't open automatically. Right-click the tray icon and choose Open Viewer, or press Ctrl+Alt+Z.
  • If the tray icon is missing, check for a startup_error.log in %LOCALAPPDATA%\Programs\PTZLite\.
  • Port 8765 may be in use by another application — check the log file for a port conflict error.

Stream engine dot stays red

  • Click the red dot to attempt a manual restart.
  • Open Settings → View Log and look for ERROR lines from go2rtc.
  • Antivirus or firewall software may be blocking go2rtc — add an exception for the PTZLite install folder.
  • Check that no other application is using port 1984 (go2rtc's internal API port).

Ctrl+Alt+Z hotkey does nothing

  • Open Settings → View Log and search for PTZLite.hotkey — the log will show whether registration succeeded or failed and the reason.
  • If registration failed, another application has already claimed Ctrl+Alt+Z. Use the system tray icon to open the viewer instead.
