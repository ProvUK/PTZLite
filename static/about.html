PTZLite

Lightweight IP camera viewer with PTZ control

What is PTZLite?

PTZLite is a self-hosted Windows desktop application for viewing and controlling multiple IP cameras in real time. It runs a local web server and opens your browser as the interface — no cloud, no subscriptions, no data leaves your network.

It was built specifically to fill the gap between basic camera apps and expensive VMS software — giving you a fast, clean multi-camera viewer with full PTZ control from a single screen.

What it does

  • Live WebRTC streaming from multiple cameras simultaneously with low latency
  • Click-to-centre PTZ control — click anywhere on the image to pan and tilt to that point
  • Joystick PTZ — click and drag on the image for continuous directional movement
  • Camera presets — save and recall PTZ positions with one click
  • Flexible grid layouts: 1×1, 2×1, 2×2, 3×2, 3×3, 4×4 with automatic pagination
  • Main and sub stream switching per session
  • Light and dark mode with preference saved across sessions
  • Stream health monitoring with auto-reconnect
  • Camera management — add, edit, disable and remove cameras from a settings page

Supported camera brands

Reolink Reolink Home Hub Pro Dahua ONVIF cameras

Reolink cameras use the native HTTP API for PTZ. Dahua cameras use the CGI API with absolute position control. Any ONVIF-compatible camera can be added for streaming; PTZ support depends on the camera's ONVIF profile.

How it works

PTZLite bundles go2rtc, an open-source RTSP-to-WebRTC bridge, which handles the stream transcoding. PTZLite configures go2rtc automatically based on your camera list — you never need to touch go2rtc directly.

The FastAPI backend handles PTZ commands, camera management, and serves the web UI. Everything runs locally on your Windows machine; your browser connects to localhost:8765.

Requirements

  • Windows 10 or 11 (64-bit)
  • Cameras must be reachable on the local network
  • A modern browser (Chrome, Edge, Firefox) — WebRTC required
  • No internet connection required after installation
